# GMod: проект, структура и нейросеть — полное руководство

> Что это: **GMod (Git Archaeologist)** — десктопное приложение (Windows),
> которое загружает Git-репозиторий, считает ~50 метрик кода, показывает
> таблицы и графы, а нейросеть (LLM + собственные ML-модели) пишет отчёты,
> оценивает риски и объясняет прогнозы.
>
> Стек: **Python + PySide6 (интерфейс) + SQLite (база) + networkx/pyqtgraph
> (графы)**. Нейросети: внешние LLM (Ollama / Groq / Gemini / OpenAI /
> Anthropic) + своя нейросеть-валидатор + свой MLP-конструктор (NumPy).

## 1. Структура проекта (где что лежит)

```
g-mod/
├── main.py                      ← точка входа (запуск приложения)
├── gmod.spec / installer.iss    ← сборка exe и установщика
├── dist/                        ← готовый GMod.exe + portable zip (не в git)
├── resources/styles/gmod.qss    ← единая тема интерфейса
└── src/gmod/
    ├── config/      settings.py (настройки), constants.py (пути и дефолты)
    ├── domain/      entities.py (сущности), schemas.py (ответы AI),
    │                prompts.py (промпты)
    ├── infrastructure/
    │   ├── parsers/   разбор кода на функции/классы (Python)
    │   ├── metrics/   ~50 метрик кода (подробно — во 2-м файле)
    │   ├── git/       чтение коммитов/diff/веток
    │   ├── llm/       провайдеры нейросетей + ZeroValidator
    │   ├── db/        SQLite: метрики, отчёты, чат, workspace
    │   └── credentials/ ключи в Credential Manager Windows
    ├── services/    бизнес-логика: ChatService, ContextAssemblyService,
    │                WorkspaceService, BackupService, LLMService,
    │                RepositoryService, ReportComparisonService
    ├── ml/          своя нейросеть с нуля (MLP на NumPy)
    ├── usecases/    сценарии: анализ репозитория, запуск «Археолога»
    └── ui/          окна: main_window.py, neural_dialog.py, theme.py
```

### Как данные текут по программе (обобщённо)

```
Git-репозиторий
      ↓  (парсер режет код на единицы: function / class)
Единицы кода (CodeUnit)
      ↓  (MetricFactory считает ~50 метрик для каждой)
SQLite → таблица raw_metrics
      ↓  (ContextAssemblyService собирает контекст)
AI-контекст: метрики + код + git-история
      ↓  (LLM: Ollama/Groq/Gemini/…)
AI-отчёт с оценкой риска 1–10 → вкладка «Отчёты»
```

## 2. Нейросеть для валидации «с нуля»

**Что это.** Крошечная нейросеть из **одного нейрона** (логистическая
регрессия `y = sigmoid(w·x + b)`), написанная вручную без sklearn/torch.
Она не анализирует код, а **проверяет саму большую нейросеть (LLM)**:
«стоит ли доверять её оценке риска?».

**Где в клиенте.** Вкладка **«Анализ» → группа «Нейросеть-валидатор»**,
а также вердикт под каждым отчётом во вкладке **«Отчёты»**
(«Валидатор: LLM-оценке можно доверять (79%)»).

**Где в коде.** `src/gmod/infrastructure/llm/validator.py`
(класс `ZeroValidator`), веса — `validator.json`, оценки —
таблицы `validator_feedback` / `validator_runs` в БД.

**Как работает (обобщённо).**
1. На вход — 5 чисел: оценка риска LLM + средние сложность/churn/размер/связность.
2. Выход — вероятность «LLM прав» (0–100%).
3. Учится градиентным спуском **на ваших оценках 👍/👎**.
4. Вердикты: ≥70% — «доверять», 40–70% — «проверить вручную», <40% — «под вопросом».

**Что может менять пользователь:** число эпох, learning rate, сами оценки
(чем больше 👍/👎, тем умнее валидатор).

## 3. Точность (ответов и заметок)

**Что это.** Доля отчётов LLM, которые вы пометили как верные.

**Где в клиенте.**
- Вкладка **«Отчёты»**: кнопки **👍 Верно / 👎 Неверно** у каждого отчёта
  + строка «Точность LLM: 73% (11/15 👍)».
- Вкладка **«Анализ» → «Нейросеть-валидатор»**: та же точность + точность
  последнего обучения валидатора.

**Где в коде.** Таблица `validator_feedback` (`src/.../db/database.py`:
`save_feedback`, `feedback_accuracy`); формула — `positive / total`.

**Как работает (обобщённо).** Каждый клик сохраняется в БД мгновенно.
Эти же оценки — обучающая выборка валидатора (п.2) и MLP (п.6).
Нет оценок → валидатор честно пишет «не обучен».

## 4. Количество эпох

**Что это.** Эпоха = один полный проход сети по всем обучающим примерам.
Больше эпох — дольше обучение, обычно точнее (до переобучения).

**Где в клиенте.** Вкладка **«Анализ» → «Нейросеть-валидатор»**:
поле **«Кол-во эпох» (1–10000)** + **Learning rate** + кнопка
**«Обучить валидатор»**. Значение сохраняется в `config.yaml`
и подставляется при следующем запуске. В новом конструкторе
(«Настроить нейросеть» → вкладка «Обучение») — поле **Epochs** + кнопки
▶/⏸/■/↻ и живой счётчик «Epoch: 73 / 500».

**Где в коде.** `ZeroValidator.train(X, y, epochs, lr)`; для MLP —
`src/gmod/ml/trainer.py` (`Trainer.fit`), ранняя остановка при достижении
целевой точности.

## 5. Функции (выбор файлов и таблица метрик)

**Что это.** Вы указываете, **какие файлы/папки анализировать**,
а программа разбирает их на функции и показывает таблицу
«функция × метрика × значение» + просит LLM описать качество словами.

**Где в клиенте.** Вкладка **«Анализ» → группа «Функции»**:
кнопки **＋ Файлы / ＋ Папка / Очистить** → список путей → кнопка
**«Анализировать выбранное»** → таблица **Файл | Функция | Метрика |
Значение** + текстовый вердикт нейросети под ней.

**Где в коде.** `AnalyzeRepositoryUseCase.analyze_paths()`
(`src/gmod/usecases/analyze_repository.py`); разбор — `parsers/`
(сейчас только Python: tree-sitter, запасной вариант — regex);
счёт — `metrics/factory.py → compute_all_metrics()`.

**Как работает (обобщённо).** Папки раскрываются рекурсивно (кроме `.git`),
поддерживаемые файлы парсятся на функции/классы, для каждой считается
~50 метрик, всё пишется в БД и рисуется в таблицу (до 2000 строк,
сортировка кликом по шапке).

## 6. Управление прогнозом и анализом

**Где в клиенте** (всё — вкладка **«Анализ»**):
- Группа **«Управление прогнозом / анализом (LLM)»**: **Температура**
  (0 — строго, 2 — фантазия), **Max tokens** (длина ответа),
  **Горизонт прогноза** (на сколько коммитов вперёд) + кнопка
  **«Построить прогноз риска»** (тренд метрик 📈/📉 + текст LLM +
  вердикт валидатора).
- Группа **«Параметры анализа»**: веса метрик (сложность/связность/
  размер/churn), порог риска 1–10, мин. уверенность, единица анализа
  (file/function/class/module), «только diff», галочки метрик,
  кнопка **«Запустить анализ»** + **Журнал** (видимые логи).
- Вкладка **«Чат»**: выбор провайдера/модели, режим контекста
  (Авто/Краткий/Стандартный/Полный), кнопка **«Что отправлено AI»**
  (инспектор контекста), AI-статус, кнопка **«Настроить нейросеть»**.

**Где в коде.** `RunArchaeologistUseCase`
(`src/gmod/usecases/run_archaeologist.py`), `LLMService`
(`src/gmod/services/llm_service.py`), `ContextAssemblyService`
(`src/gmod/services/context_service.py`).

## 7. Большой конструктор нейросети (MLP с нуля)

Кнопка **«Настроить нейросеть»** в чате открывает диалог из 6 вкладок:
**Данные** (источник: метрики проекта / SQLite / CSV / JSON),
**Архитектура** (вход–скрытые–выход, напр. 8→16→8→1; активации
ReLU/Sigmoid/Tanh/Linear/Softmax), **Обучение** (Epochs/LR/Batch/
Target accuracy/сплит/seed + график loss/accuracy на pyqtgraph),
**Прогноз** (выбор объекта + порог-слайдер, меняющий результат),
**Анализ** (accuracy/precision/recall/F1/confusion matrix + кнопка
«Объяснить результат через AI»), **История** (Model v1/v2/… —
открыть и переиспользовать).

Код: `src/gmod/ml/` (9 файлов: слои, forward/backprop/update —
всё своё, из библиотек только NumPy). Обучает всегда `NeuralNetwork`,
LLM только объясняет результат.

## 8. Запуск на другом компьютере (про portable zip)

Файл `dist\GMod-portable.zip` (~117 МБ) содержит папку `GMod`:
`GMod.exe` + `_internal` (Python 3.10, PySide6, все библиотеки,
`VCRUNTIME140.dll` — внутри, ничего доустанавливать не надо).

**Будет ли работать на другом ПК? Да, если:**
1. Windows 10/11 **x64**;
2. Распаковать zip **целиком** (exe без папки `_internal` не запустится);
3. Интернет — только для облачных нейросетей (Groq/Gemini/OpenAI/Anthropic);
   локальная Ollama — по желанию.

**Что нужно знать:**
- Python устанавливать **не нужно** — он внутри.
- Настройки/база/веса создаются сами в `%APPDATA%\GMod` при первом запуске.
- **API-ключи НЕ переезжают**: они в Credential Manager *вашего*
  пользователя Windows. На новом ПК их надо ввести заново один раз
  (Настройки → AI-провайдеры). Исключение — локальная Ollama без ключа.
- Антивирус может ругнуться на неподписанный exe (норма для PyInstaller) —
  добавить в исключения.
- Альтернатива zip — установщик через `installer.iss` (нужен Inno Setup).
